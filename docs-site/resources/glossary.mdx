---
title: "Glossary"
description: "Plain definitions of the terms used in these docs."
---

| Term | Meaning |
| --- | --- |
| AMM | A pool of two tokens where a formula sets the price (Aquarius, Soroswap, Sushi) |
| Band | How far the average sale price may fall below the fair price: 2%, 10%, 25% |
| Collateral | What a borrower deposits so the lender can sell it if the loan is not repaid |
| Collateral factor | The share of the collateral's value that may be borrowed |
| Exit liquidity | Dollars that could be raised selling before the price falls past a band |
| Fail closed | When unsure, publish nothing rather than a wrong number |
| Liquidation bonus | The discount a liquidator gets for clearing a bad loan |
| Order book | A list of offers to buy and sell at set prices; Stellar's is the SDEX |
| Oracle | A service that brings outside data, usually prices, onto the blockchain |
| Reference price | The one fair price every market is measured from |
| RWA | Real-world asset: a token backed by something like a government bond |
| SAC | Stellar Asset Contract: the Soroban contract address of a classic Stellar asset |
| SEP-1 / stellar.toml | The file on an issuer's website that lists its official tokens |
| Soroban | Stellar's smart-contract platform |
| Safe limit (cap) | The most of a token a lender should accept as collateral |
